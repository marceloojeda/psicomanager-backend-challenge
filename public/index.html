Documentação interativa completa com suporte total à autenticação JWT.

🚀 Como Usar a API

  1. Acesse a documentação clicando em "Ver Documentação" abaixo
  2. Faça login usando POST /auth/login com suas credenciais
  3. Copie o access_token da resposta de login
  4. Clique "Authorize" no Swagger e cole o token
  5. Use todas as APIs - agora você tem acesso completo!
