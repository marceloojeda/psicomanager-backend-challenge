🔐 PsicoManager API - JWT Authentication Required

Todas as rotas requerem autenticação JWT

Use o botão "Authorize" abaixo para configurar seu token

📋 Como Usar a Autenticação

🆕 Primeira vez usando a API?

Você precisa criar uma conta primeiro! Use o endpoint POST /users (público) para se registrar antes de fazer login.

  1. Faça Login: Use POST /auth/login com o email e password criados
  2. Copie o Token: Copie o "access_token" da resposta do login
  3. Clique "Authorize": Cole o token no campo de autorização (🔓)
  4. Teste as APIs: Agora você pode usar todas as rotas protegidas

💡 Dicas Importantes:

  • O token expira em 1 hora. Use POST /auth/refresh para renovar
  • Apenas POST /users e POST /auth/* são públicos
  • Todas as outras rotas requerem JWT no header Authorization

👥 Sistema de Roles (Autorização)

A API possui dois níveis de acesso:

  • Role "user" (padrão): Acessa apenas suas próprias tarefas
  • Role "admin": Acesso completo a todas as tarefas e gerenciamento de usuários

💼 Criação de usuários:

  • Campo "role" é opcional no POST /users
  • Valores aceitos: "user" ou "admin"
  • Se não informado, usuário será criado com role "user"
